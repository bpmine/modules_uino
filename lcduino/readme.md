# LCDUINO - Ecran LCD Wifi déporté

Cet écran connecté permet d'afficher des informations fournies sur le réseau.

Un bouton permet d'interragir avec l'écran:
- Mise en veille
- Acquittement d'un message
- Réveil

## Mode d'emploi

Le boîtier est connecté en permanence au réseau local. Un serveur ouvert permet à un client du réseau d'envoyer des messages et des commandes à l'écran. Le boîtier est donc toujours accessible.

L'écran passe en veille au bout d'une heure.
Un appui sur le bouton permet de réveiller l'écran.

Un appui long sur le bouton fait passer l'écran en veille.

Lorsqu'un nouveau message est affiché, un symbole indique qu'il n'est pas encore lu. Pour marquer le message comme lu, l'utilisateur appuye brièvement sur le bouton. Le message est alors acquitté.

Un site web est accessible en permanance. Il permet de:
- Indiquer ce qui est actuellement affiché à l'écran
- Indiquer si le dernier message a été acquitté ou non
- Afficher un nouveau message
- Envoyer des commandes (ex: Afficher un chat, un chien, faire bip, ...)
